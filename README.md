# VRUKSH- Interactive-Educational-Speaking-Tree-Bot
Developed VRUKSH, an AI-powered Interactive Educational Speaking Tree Robot designed to provide real-time educational assistance through voice-based interaction. The system uses Raspberry Pi 4B, Speech-to-Text (Vosk), Qwen2.5 Small Language Model through Ollama, and Text-to-Speech (Piper) to enable natural two-way communication.

Implemented an offline AI voice assistant that can listen to user queries, process natural language, generate intelligent responses, and communicate through a speaker. Integrated a round LCD display to show animated emotional states such as Listening and Speaking.

Designed the hardware architecture, circuit connections, and 3D model of the robotic tree. Configured the system to automatically start on boot and operate without internet connectivity.

Technologies Used: Python, Raspberry Pi 4B, Vosk, Qwen2.5, Ollama, Piper TTS, Speech Recognition, Natural Language Processing (NLP), Small Language Models (SLM), and Edge Computing.

Objective: To make interactive and accessible AI-powered education available, especially in rural and under-resourced areas.
